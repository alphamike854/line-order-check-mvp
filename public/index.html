ดูรหัสเหมือนหน้า Order Board เลือกได้หลายรหัส แล้วให้ระบบแบ่งเป็นหลายรอบตามลิมิตของคลังให้อัตโนมัติ

คลังปลายทาง

เลือกได้มากกว่า 1 คลัง ระบบจะสลับคลังและแบ่งรอบอัตโนมัติ เช่น ส่วนเกิน 25 / ลิมิต 5 = 5 รอบ

ประวัติรอบส่ง

หนึ่งครั้งที่ผู้ใช้ยืนยัน อาจถูกแบ่งเป็นหลายรอบตามลิมิตของแต่ละคลัง

รหัส Point พิเศษจริง

กำหนดภายหลังได้ก่อนปิดยอด ระหว่างที่ยังไม่ครบ ระบบใช้ Point Reserve แบบกรณีเสี่ยงสูงสุดเพื่อคำนวณการกระจายความเสี่ยง

รายงานประจำวัน

รายงานแยกตามชุดยอด แม้เปิดใหม่ในวันที่เดียวกันก็ไม่สะสมกับชุดที่ปิดไปแล้ว

รายการต้องตรวจสอบ

แก้ข้อความ → ตรวจผล Parser → ยืนยัน จึงจะเปลี่ยนยอดจริง ระบบจะ Parse ซ้ำที่ Server ก่อนบันทึกเสมอ

ข้อความที่ถูก Unsend

ตัวคูณ Point พิเศษของบริษัท

ค่าบริษัทใช้กับยอดที่กำลัง OPEN ทันทีเมื่อบันทึก ส่วนชุดที่ CLOSED จะเก็บค่าเดิมไว้เป็นประวัติ

Point ที่ยอมติดลบได้

Risk Budget = ยอดหลังหัก % + Point ที่บริษัทยอมรับให้ติดลบได้ ระบบจะเริ่มแนะนำให้กระจายเมื่อ Point Reserve สูงกว่า Risk Budget

ลิมิตคลังปลายทางต่อรอบ
